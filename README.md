# Adidas Sales Dashboard | Power BI

## 📌 Project Overview
The Adidas Sales Dashboard is a data visualization project created using Microsoft Power BI. It helps analyze Adidas sales performance and understand sales trends through interactive charts, graphs, and key performance indicators (KPIs).

## 🎯 Project Objectives
- Analyze Adidas sales performance.
- Understand sales trends over time.
- Compare sales across different product categories and regions.
- Identify top-performing products and sales channels.
- Present business insights using an interactive dashboard.

## 🛠️ Tools & Technologies
- **Microsoft Power BI** – Dashboard development and data visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculations and measures, where applicable
- **Microsoft Excel / CSV** – Data source, if used

## 📊 Key Features
- Sales performance overview
- Total sales and profit analysis
- Regional sales comparison
- Product category analysis
- Sales trends over time
- Interactive charts and filters, where available

## 🔍 Key Insights
The dashboard can help users:
- Understand overall sales performance.
- Identify high-performing products and regions.
- Compare sales and profitability.
- Analyze changes in sales over time.
- Support data-driven business decisions.

## 📁 Project Files
- `Adidas Dashboard.pbix` – Power BI dashboard file
- `README.md` – Project documentation
- `screenshots/` – Dashboard screenshots, if included

## 🚀 How to View the Project
1. Download the `Adidas Dashboard.pbix` file from this repository.
2. Install Microsoft Power BI Desktop.
3. Open the downloaded `.pbix` file in Power BI Desktop.
4. Explore the report pages, charts, and filters.
